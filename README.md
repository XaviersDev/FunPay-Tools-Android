*   📉 **XD Dumper 2.0** - переписан 1:1 как Cardinal-плагин. Pinned-режим, авто-патч обязательных полей, защита от провала ниже минимума, минимальный интервал 1 секунда.

*   🛒 **Вкладка «Продажи»** - все заказы в одном экране: количество и сумма за сегодня, кликабельные заказы с переходом в чат, история по покупателям.
*   😂 **Лента смешных отзывов** - скролль и лайкай смешные отзывы FunPay прямо в приложении, добавляй свои.

*   🧠 **ИИ-переменные** - динамические переменные с обращением к нейросети в шаблонах. Разрешения какие данные ИИ видит. *(PRO)*
*   🌙 **Always On Screen** - поставьте старый телефон рядом, он будет 24/7 показывать инфу аккаунта. 10 видов экрана. *(PRO / Реклама)*
*   🌍 **Live-перевод чатов** - авто-перевод входящих сообщений в реальном времени. Кнопка в топбаре чата.
*   💎 **Каталог шаблонов** - готовые наборы автоответов, шаблонов, ИИ-настроек из [funpay.tools/catalog](https://funpay.tools/catalog).
*   🎨 **Темы из изображений** - загрузи картинку, цвета темы сгенерируются автоматически.

### 💬 1. Мессенджер на максималках

Больше не нужно заходить через браузер. Полноценный чат с FunPay прямо в приложении.

*   **Список чатов** с индикацией непрочитанных, цветными метками, папками
*   **Сталкер-мод** - какой лот смотрит покупатель, дата регистрации, язык
*   **Кнопки-шаблоны** с переменными (`$username`, `$welcome`, `$date`)
*   **Настраиваемая нечиталка** - бот пишет → не прочитано, ты пишешь → прочитано
*   **Отправка до 10 фото** одним пакетом с превью и задержками 800мс
*   **Вставка картинок из буфера обмена** прямо в поле ввода
*   **Выделение сообщений зажатием** - режим как в Telegram, копирование с автором и временем
*   **Ответ на сообщение** - кнопка Reply на пузыре, свайп влево, цитата совместима с FunPay
*   **Поиск по переписке** с подсветкой и навигацией
*   **Live-перевод входящих** - кнопка в топбаре чата
*   **«Прочитать ещё»** для длинных сообщений
*   **История заказов с покупателем** - кнопка-бумажка в топбаре
*   **Триггеры-вызовы** (`!продавец` → критическое уведомление как звонок)
*   **Копирование ссылки чата** в меню на три точки
*   **Встроенный браузер FunPay** прямо в приложении

### 🚀 2. Автоматизация продаж

*   **Умное авто-поднятие лотов** - читает кулдаун из ответа FunPay (а не фиксированный интервал)
*   **XD Dumper 2.0** - переписан 1:1 как Cardinal-плагин: pinned-режим, авто-патч полей, защита от провала, минимум 1 секунда
*   **Автовыдача товаров** - полная как в Cardinal: списки, шаблоны под лот, история выдач (PRO / Реклама)
*   **FunPay Concurent** - авто-реклама в игровых чатах FunPay, встроенный браузер для добавления чатов (PRO)
*   **Вечный онлайн** - отдельный переключатель «Всегда онлайн»
*   **Мульти-аккаунты + прокси** - несколько аккаунтов параллельно через свой прокси
*   **Расписания режима занятости** - кастомное расписание
*   **Авто-тикеты в ТП** за неподтверждённые заказы
*   **Авто-напоминания клиентам** подтвердить заказ
*   **Бонус за отзыв** - авто-бонус когда клиент оставил отзыв
*   **Регистр в командах** - настройка чувствительности к регистру

### 🤖 3. ИИ-Ассистент

Встроенный искусственный интеллект помогает общаться с покупателями профессионально.

*   **ИИ-переменные** - динамические переменные с обращением к нейросети прямо в шаблонах (PRO)
*   **Разрешения для ИИ** - контроль какие переменные ИИ видит
*   **ИИ-ответы на отзывы** - уникальные ответы с учётом названия товара и оценки
*   **Умное авто-приветствие** - кулдаун работает правильно, для каждого пользователя свой
*   **Авто-перевод RU→EN** описания лотов в один тап через Google-хак без потери эмодзи и символов

*   **Горизонтальный режим** - больше не залипает
*   **Оконный режим Android** - открывается с первого раза, копи-пейст работает
*   **Листание отзывов** в профилях больше не вылетает
*   **Уведомления на свои сообщения** - больше не приходят
*   **Дабл-клик фото** - больше не отправляется 2 раза при плохом интернете
